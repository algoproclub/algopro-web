Our IDE

We host an online IDE at ide.algopro.hu, which we use for our programming classes. Our students can write and execute code for class exercises found on sites such as Codeforces and AtCoder. It also supports executing test cases. Finally, teachers can view their students' submissions to check their progress, and even edit if necessary.

There is a submission feature built into the IDE that allows pushing the solutions to the original problem site and fetching the test results. This simplifies the lives of our students, who would otherwise need to visit the site, submit and later check the results, and our teachers as well, since they can see everything in a single window.

Submission bot features

The programming sites we use for our classes have secret test cases we could not duplicate for our students (public tests can be executed directly in the IDE). To solve this, we submit their code directly, then import the results into our user interface without any further clicks required.

Code submission

Upload students' code to a programming site

Fetching test results

Upon completion of the tests, import the results

Autonomy (or the lack of it)

Our submission bot never acts on its own, only upon request by our users (all students or teachers of our organization, there is no public IDE access).

It's definitely not an AI agent!
